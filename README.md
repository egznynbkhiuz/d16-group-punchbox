## Overview

D16 Group PunchBOX is a dedicated kick drum synthesizer featuring four independent synthesis layers—transient, body, sub, and snap—for crafting perfect electronic kick drums from EDM to techno.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D16 Group PunchBOX** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Layers** | Transient click, body tone, sub oscillator, and snap layer combine independently |
| **Synthesis Engine** | FM, sample, and sine oscillator engines per layer for maximum variety |
| **Tone Shaping** | Per-layer pitch envelope, decay, and level give precise control |
| **Sidechain Output** | Dedicated sidechain output for triggering external compressors |
